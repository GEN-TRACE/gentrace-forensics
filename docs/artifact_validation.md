# 아티팩트 복원 검증 기록

검증일: 2026-09-21. 코드의 자동 검증과 실제 자료의 관측 결과를 분리한다. 실제 원본·본문·식별자·서명 URL은 이 문서에 포함하지 않는다.

## 시나리오1 캐시 누락 수정 후 검증

사용자가 ChromeCacheView에서 확인한 이미지 2개를 대조해, 기존 인덱스 순회만으로는
캐시의 잔존 엔트리를 놓친다는 사실을 확인했다. 따라서 아래 과거의 `574건/9개`
결과는 전체 캐시 아티팩트 수가 아니다. 9개 또한 기본 음성 카탈로그 오탐이었고,
파일 문맥 없는 미리듣기 URL은 사용자 파일 자산에서 제외하도록 수정했다.

실제 E01에서 획득한 **Cache_Data만** 최종 코드로 다시 분석했다. Downloads 및
History는 이 검증과 복원 결과의 입력으로 사용하지 않았다.

- 인덱스 엔트리 574개 + 헤더·키 체크섬 검증을 통과한 추가 블록 엔트리 760개 = 1,334개.
- 아티팩트 34개, 내보낸 파일 11개. PNG 5개와 WebP 미리보기 3개가 전체 디코딩을 통과했다.
- DOCX 1개는 구조 검증 완료, 그 밖의 파일 2개는 미검증 상태로 보존했다.
- 사용자 스크린샷의 이미지 2개는 캐시 파일 식별자와 실제 이미지 화면을 대조했다.
- 내보낸 파일의 크기·SHA-256, SQLite/JSONL 일치, 외래 키, 보고서의 로컬 링크를 검증했다.
- 결과: `outputs/scenario1-cache-recovered-20260921/report/index.html`.
- 수정 후 회귀 검사: 로컬 캐시 비의존 테스트 212 passed, 1 skipped, 11 deselected
  (별도 캐시 테스트 파일 제외), 실제 시나리오1 캐시를 사용한 파서·분류 검사 50 passed.
  두 실행에는 공통 테스트가 있으므로 합산하지 않는다. Ruff와 Mypy도 통과했다.
  DeepFake 캐시를 포함한 전체 재검사는 클라우드 파일 읽기 지연으로 완료하지 못했다.

추가 엔트리는 인덱스 연결 여부와 블록 할당 상태를 출처에 남긴다. 파일의 형식 검증은
획득 시점의 활성 상태나 사용자의 생성·업로드 행위를 확정하지 않는다.

## DeepFake_DeepVoice E01 획득 및 최종 재분석

실제 E01을 열어 논리 이미지 해시 계산, 프로필·캐시·네트워크 상태 획득, 분류·정규화·복원·보고서 생성을 완료했다. 이후 새 획득본의 `acquired.json`을 최종 코드의 `analyze`에 전달해 파일 크기·SHA-256을 다시 확인하고 재분석했다. 아래 수치는 최종 재분석 결과다.

| 지표 | 결과 |
|---|---:|
| 캐시 관측 / 기존 정규화 레코드 | 2,285 / 2,285 |
| 고유 파일 자산 레코드 | 145 |
| 구조화된 근거 또는 로컬 URL 참조에 연결 | 73 |
| 경로·이름만 맞는 후보 | 72 |
| 입력 관련 / 생성 관련 / 역할 미확정 자산 | 6 / 28 / 111 |
| 확보 표현 검증 완료 자산 / 부분 복원 자산 | 79 / 7 |
| 메타데이터만 있는 자산 | 59 |
| 내보낸 파일 | 99 |
| 형식·범위 검증을 통과한 미디어 표현 | 81 |
| 부분 구간 파일 / URL 참조 텍스트 | 16 / 2 |
| 전체 구간 조립 및 FFmpeg 디코딩을 통과한 MP4 | 6 |
| Network Persistent State 레코드 | 190 |

자산, 표현, 파일 개수는 다른 지표다. `complete`인 미리보기·커버를 업로드 원본이나 원본 생성 영상으로 세지 않는다. 역할 미확정 후보도 내용 검증을 통과할 수 있다.

서비스별 관측:

- DeeVid: 98개 자산. 입력 관련 3, 생성 관련 12, 미확정 83. 이력 미연결 CDN 이미지의 역할은 미확정이다. 부분 영상 구간을 별도로 내보내며 6개 영상 표현이 전체 디코딩을 통과했다.
- ElevenLabs: 44개 자산. 입력 관련 3, 생성 이력 관련 16, 미리듣기·그 밖의 미확정 25. 모두 파일 정보만 확보했으며 복원 오디오로 집계하지 않았다.
- Gemini: 3개 자산에 이미지 변형과 로컬 URL 참조를 연결했다. 이름 패턴만으로 입력/생성 역할을 확정하지 않았다.
- Network Persistent State: 획득 및 해시 검증 완료. 서버 상태 190개 중 DeeVid 3, ElevenLabs 4, Gemini 1, 서비스 미분류 182개다. 대체 서비스 만료 시각 145개는 방문 시각과 구분했다. ChatGPT·Claude로 분류된 네트워크 기록은 이번 자료에서 관측되지 않았다.

내보낸 파일 99개의 크기·SHA-256, 보고서의 로컬 링크 존재 여부, SQLite 레코드 일치와 foreign key, 후보 역할, 정규화의 actor 미확정을 별도로 확인했다. 보고서 브라우저 시각 검토는 컴퓨터 사용 권한이 제공되지 않아 수행하지 못했다. HTML 생성·이스케이프·링크와 파일 디코드는 자동 검증했다.

## E01 재실행·scenario1 범위

이번 E01 전체 실행은 `outputs/e01-artifacts-native-20260921`에 보관했다. 실행 중 URL 참조를 이미지 자산에 연결하는 수정이 추가되어, 최종 코드는 새 획득본을 `outputs/e01-artifacts-verified-20260921`로 재분석했다. 네이티브 실행의 저장 결과에 대해 통합 테스트의 출처·해시·정규화·SQLite·복원 상태 검증을 별도로 다시 실행해 통과했다. 최종 재분석도 파일 99개, 자산 145개, 정규화 2,285개, 네트워크 190개의 저장 결과를 대조했다.

scenario1의 `01_Cache_Data`는 E01 자체가 아닌 로컬 캐시 자료다. 원래 파일명과 크기·해시를 기록한 235개 캐시 파일로 획득 매니페스트를 만들고 재분석했다. 574개 캐시 관측, 9개 메타데이터 자산이 나왔으며 해당 파일 본문은 복원되지 않았다. 클라우드 읽기 지연 후 완료했으며, scenario1 E01 전체 실행으로 표기하지 않는다.

```bash
GENTRACE_E01_FIXTURE=/path/to/evidence.E01 \
GENTRACE_E01_OUTPUT=outputs/native-check-new \
python -m pytest -q -s tests/test_e01_integration.py
```
