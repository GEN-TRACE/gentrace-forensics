# 아티팩트 복원 검증 기록

검증일: 2026-09-21. 코드의 자동 검증과 실제 자료의 관측 결과를 분리한다. 실제 원본·본문·식별자·서명 URL은 이 문서에 포함하지 않는다.

## DeepFake_DeepVoice 획득본 재분석

이전에 E01에서 정상 획득한 프로필의 `acquired.json`을 `analyze`에 전달했다. 획득 파일의 크기·SHA-256을 다시 확인한 뒤 분류·정규화·복원·보고서를 실행했다.

| 지표 | 결과 |
|---|---:|
| 캐시 관측 / 기존 정규화 레코드 | 2,285 / 2,285 |
| 고유 파일 자산 레코드 | 145 |
| 구조화된 근거 또는 로컬 URL 참조에 연결 | 73 |
| 경로·이름만 맞는 후보 | 72 |
| 입력 관련 / 생성 관련 / 역할 미확정 자산 | 6 / 28 / 111 |
| 확보 표현 검증 완료 자산 / 부분 복원 자산 | 79 / 7 |
| 메타데이터만 있는 자산 | 59 |
| 내보낸 파일 | 99 |
| 형식·범위 검증을 통과한 미디어 표현 | 81 |
| 부분 구간 파일 / URL 참조 텍스트 | 16 / 2 |
| 전체 구간 조립 및 FFmpeg 디코딩을 통과한 MP4 | 6 |

자산, 표현, 파일 개수는 다른 지표다. `complete`인 미리보기·커버를 업로드 원본이나 원본 생성 영상으로 세지 않는다. 역할 미확정 후보도 내용 검증을 통과할 수 있다.

서비스별 관측:

- DeeVid: 98개 자산. 입력 관련 3, 생성 관련 12, 미확정 83. 이력 미연결 CDN 이미지의 역할은 미확정이다. 부분 영상 구간을 별도로 내보내며 6개 영상 표현이 전체 디코딩을 통과했다.
- ElevenLabs: 44개 자산. 입력 관련 3, 생성 이력 관련 16, 미리듣기·그 밖의 미확정 25. 모두 파일 정보만 확보했으며 복원 오디오로 집계하지 않았다.
- Gemini: 3개 자산에 이미지 변형과 로컬 URL 참조를 연결했다. 이름 패턴만으로 입력/생성 역할을 확정하지 않았다.
- 해당 재분석 입력은 이전 획득본이므로 Network Persistent State는 `not_collected`다. 원래 이미지에 네트워크 상태가 없다는 뜻이 아니다.

내보낸 파일 99개의 크기·SHA-256, 보고서의 로컬 링크 존재 여부, SQLite 레코드 일치와 foreign key, 후보 역할, 정규화의 actor 미확정을 별도로 확인했다. 보고서 브라우저 시각 검토는 컴퓨터 사용 권한이 제공되지 않아 수행하지 못했다. HTML 생성·이스케이프·링크와 파일 디코드는 자동 검증했다.

## E01 재실행·scenario1 범위

기존 E01 전체 실행 성공 기록은 이전 파이프라인의 기록이다. 이번 변경으로 네이티브 재실행을 시도했으나 이미지가 macOS의 `dataless`(클라우드 보관) 상태여서 최초 실행은 파일 읽기 시간 초과로 실패했다. 이를 새 코드의 E01 전체 실행 성공으로 기재하지 않는다. 로컬로 완전히 다운로드한 E01에서 `tests/test_e01_integration.py`를 다시 실행해야 한다.

scenario1의 `01_Cache_Data`는 E01 자체가 아닌 로컬 캐시 자료다. 원래 파일명과 크기·해시를 기록한 235개 캐시 파일로 획득 매니페스트를 만들고 재분석했다. 574개 캐시 관측, 9개 메타데이터 자산이 나왔으며 해당 파일 본문은 복원되지 않았다. 클라우드 읽기 지연 후 완료했으며, scenario1 E01 전체 실행으로 표기하지 않는다.

```bash
GENTRACE_E01_FIXTURE=/path/to/evidence.E01 \
GENTRACE_E01_OUTPUT=outputs/native-check-new \
python -m pytest -q -s tests/test_e01_integration.py
```
